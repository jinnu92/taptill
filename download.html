Install in a few minutes

TapTill is new and not yet signed with a paid publisher certificate, so Windows and Mac ask you to confirm the first time. This is expected.

Windows

  1. Open TapTill-2.1.0-Setup.exe from your Downloads.
  2. If you see “Windows protected your PC”, click More info, then Run anyway.
  3. Follow the installer. Tick “Create a desktop shortcut” if you want one.
  4. Open TapTill from the Start menu or the desktop.
  5. Set your Admin name and PIN, then add your menu or upload it from Excel.

Mac

  1. Open the .dmg file and drag TapTill into Applications.
  2. Open TapTill from Applications. If the Mac says it can’t be opened or “Apple could not verify” it, click Done.
  3. Open System Settings → Privacy & Security, scroll down and click Open Anyway next to TapTill. Confirm with your Mac password.
  4. Click Open when asked again. From now on it opens normally.
  5. Set your Admin name and PIN, then add your menu or upload it from Excel.
Updating later? Your bills, menu and settings stay in the TapTill folder on your computer and are kept when you install a newer version, reinstall or uninstall. TapTill can also install a signed update file from Settings → Help, and takes a backup first.

What you need

Computer

  • Windows 10 or 11 (64-bit), or a Mac with Apple silicon or Intel
  • Google Chrome or Microsoft Edge, for silent printing (TapTill opens in it like an app)
  • Touchscreen optional: keyboard and mouse work fully
  • No internet needed for daily use

Printer

  • 80 mm or 58 mm USB thermal receipt printer
  • Install the printer maker’s driver so it shows up as a normal printer
  • Make it the default printer, then pick 80 or 58 mm in Settings → Printer & KOT
  • Turn on KOT there to print kitchen tickets too
  • Print a test bill from an order; it prints without a dialog in Chrome or Edge

Optional extras

  • A Wi-Fi router for phones, tablets and table QR ordering (Pro); internet not required
  • A TV or spare screen for the customer display (Pro)
  • A USB drive or Google Drive/OneDrive folder for extra backups
  • An integration partner account for Swiggy/Zomato orders (Pro)
